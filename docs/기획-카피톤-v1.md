## 0. 톤 헌법 (한 문장)

**다정한 고양이가 나와 함께 동네를 누비며 조용히 응원한다.** 감시하지 않고, 조르지 않고, 축하한다.

- 결: 동물의숲 / 피크민 블룸. 심시티·경찰·감시 **아님**(결정기록 §3).
- 동사: "짓다(construction)" ❌ → **"가꾸다·키우다·자라다·누비다(nurture/explore)"** ⭕.
- 화자: **내 고양이(동반묘)** — 나의 짝꿍. 함께 다니는 친구. **냥체**(고양이 말투, 어미에 '~냥'). 1인칭은 "나/내가". 다정하되 감시·재촉 어감은 절대 금지.

## 1. 절대 금지 (감시 어감 차단)

위치 앱에서 "동선을 지켜본다"는 어감은 독(결정기록 §3).

| 금지 | 이유 | 대체 |
|---|---|---|
| "보안관/경찰/순찰/감시/추적/동선" | 감시 불안 | "다녀온 곳", "발자국", "우리가 누빈 곳" |
| "당신을 감지했습니다", "위치가 확인됨" | 시스템·감시 톤 | "○○ 왔다냥" |
| "점수 획득 +10", "랭킹 3위" | 점수판 없음(범위정의 §5) | 성장 자체로 표현("작은 집이 됐다냥") |
| "미션 실패", "벌점", "감쇠" | 벌주지 않음 | 긍정만 |
| "체크인 안 하면 놓쳐요" (FOMO) | 조르는 톤 | 부드러운 초대 |
| 딱딱한 명령형("~하시오") | 차가움 | 청유·제안형("~해볼까냥") |

## 2. 고양이 말투 (Voice) — 냥체

**성격:** 다정하고 느긋한 내 짝꿍 고양이. 재촉하지 않고, 내가 뭘 하든 반겨준다. 작은 것도 같이 기뻐하고, 안 가본 골목을 궁금해한다.

**냥체 규칙**
- 어미에 **'~냥'** 을 붙인다. 평서문 "~해요/~예요" → "~한다냥/~이냥", 청유 "~볼까요" → "~볼까냥", 의문 "~나요?" → "~냥?/~냐옹?". (예: 됐어요→됐다냥, 좋아요→좋다냥, 가볼까요→가볼까냥)
- **1인칭은 "나/내가"** (고양이 본인이 말함). "제가/저랑" 같은 겸양 해요체는 쓰지 않는다.
- **과함은 절제:** 어미와 1인칭만 고양이로. ㄹ→ㅇ 같은 아기말·받침 뭉개기는 쓰지 않는다(가독성·따뜻함 유지). 이모지는 문장당 최대 1개, 없어도 됨.
- 짧게. 한 번에 1~2줄(지도/시트에 얹히므로 길면 방해).
- "우리 동네", "여기", "또 왔다냥", "같이 가볼까냥" — 함께함·소속감·재방문을 자연스럽게.
- 성장·숫자는 사람을 주어로("네가 이만큼 누볐다냥"), 시스템을 주어로 하지 않기.
- 고양이는 **딱 1마리**, 표정/상태 몇 개(등장/축하/안내/감정). 도감식 수집 금지(세계관 §6).

> **적용 범위:** 냥체는 **고양이가 말하는 대사**(상주 인사·알림·축하·안내·빈 상태·오류)에 적용한다. **버튼/탭 라벨 같은 UI 액션 텍스트**("발자국 남기기", "순간 남기기 📷")는 기능 명료성을 위해 평어로 둔다(§4).

**예시**
- 상주 인사: "우리 동네, 오늘도 조용하고 좋다냥."
- 미개척 유도: "저쪽 골목은 아직 안개냥. 같이 가볼까냥?"
- 성장 축하: "여기, 이제 작은 집이 됐다냥 🛖"

## 3. 상황별 카피 (샘플 — 디자인 확정 전 초안)

### 3.1 온보딩

| 단계 | 카피(초안) |
|---|---|
| 환영 | "안녕하냥! 나랑 같이 우리 동네를 누벼볼까냥?" |
| 고양이 정하기 | "이 친구, 이름을 지어줄래냥? 털색도 골라보라냥." |
| 위치 권한 | "어디를 다녀왔는지 알아야 발자국을 남길 수 있다냥. 위치를 켜줄래냥?" |
| 알림 권한 | "도착하면 내가 살짝 알려줄게냥. 알림만 켜두면 된다냥." |
| 내 동네 확인 | "여기가 우리 동네가 맞냥?" |
| 튜토리얼 3컷 | ① "다녀온 곳에 발자국을 남기고" ② "발자국이 쌓이면 아지트가 자란다냥" ③ "안개가 걷히면 내가 뛰어놀 곳이 넓어진다냥." |
| 첫 발자국 | "자, 지금 여기. 첫 발자국을 남겨볼까냥?" → (탭 후) "🐾 첫 발자국이 찍혔다냥. 여기서부터 시작이냥." |

### 3.2 도착 알림 (지오펜스 — 유일한 알림)

- 기본: **"○○ 왔다냥! 발자국 남길까냥?"**
- 단골(재방문): "또 왔다냥, ○○. 여기 자주 오는구냥 :)"
- 찜한 곳 첫 방문: "가고 싶다던 ○○, 드디어 왔다냥!"
- 야간/방해금지 존중, 스팸 금지(기능명세 §3.1).

### 3.3 체크인 시트

| 상황 | 카피 |
|---|---|
| 다음 단계 힌트 | "한 번 더 오면 여기가 **작은 집**이 된다냥." / "두 번만 더 오면 캣타워가 될 것 같다냥." |
| 발자국 버튼 | "발자국 남기기" (라벨 — 평어 유지) |
| 사진 버튼 | "순간 남기기 📷 (선택)" (라벨 — 평어 유지) |
| 근접 밖 | "조금만 더 가까이 가면 발자국을 남길 수 있다냥." |
| 위치 못 잡음 | "잠깐, 위치를 확인하고 있다냥…" |

### 3.4 성장 축하 (등급업 순간)

- 발자국→박스: "여기 박스가 생겼다냥 📦 마음에 드나 보다냥."
- 박스→작은 집: "작은 집이 됐다냥 🛖 자주 오는구냥."
- 작은 집→캣타워: "캣타워다냥 🗼 여긴 우리 단골이냥."
- 캣타워→캣 팰리스: "🏰 캣 팰리스다냥. 여긴 네 인생 장소냥."
- 거시 진화: "우리 동네가 이제 **아늑한 동네**가 됐다냥." / "여기, 이제 **고양이 영역**이다냥. 네가 이만큼 누볐다냥."

### 3.5 아지트 상세 (고양이의 추억)

| 요소 | 카피 |
|---|---|
| 사진 있음 | "여기서의 순간들" (섹션 라벨 — 평어) |
| 사진 없음(빈 상태) | "아직 남긴 순간이 없다냥. 다음에 오면 하나 남겨볼까냥?" |
| 발자국 수 | "지금까지 N번 다녀왔다냥" |

### 3.6 빈 상태·엣지 (슬프지 않게)

| 화면 | 카피 |
|---|---|
| 위시리스트 0 | "가고 싶은 곳이 있냥? 검색해서 찜해두면 지도에 표시된다냥." |
| 코스 후보 0 | "이 근처는 벌써 다 개척했다냥! 대단하다냥." |
| 탐색 결과 0 | "음, 못 찾았다냥. 다른 이름으로 찾아볼까냥?" |
| 오프라인 | "지금은 연결이 안 된다냥. 발자국은 잘 저장해뒀다가 연결되면 남겨둘게냥." |
| 위치 권한 거부 | "위치가 꺼져 있어서 발자국을 남기기 어렵다냥. 켜두면 내가 도와줄게냥." (비난 없음) |

### 3.7 시스템/계정

- 로그아웃: "다음에 또 만나자냥."
- 계정 탈퇴 확인: "정말 떠나냥? 그동안 함께 누빈 동네와 순간들이 모두 지워진다냥." (되돌릴 수 없음, 담백하게)
- 오류: "앗, 잠깐 문제가 생겼다냥. 다시 해볼까냥?" (기술 용어·에러코드 노출 금지)

## 4. 마이크로카피 원칙 (버튼·라벨)

- 버튼·탭 라벨은 **평어로 명료하게**: "발자국 남기기", "순간 남기기", "여기 첫 발자국", "같이 가볼까요". (냥체는 고양이 대사에만 — §2 적용 범위.)
- 라벨은 짧게, 시스템 용어 금지("동기화 완료" ❌ → 조용히 처리).
- 숫자는 성장의 근거로만("N번 다녀옴"), 경쟁·점수로 쓰지 않기.
- 이모지: 등급 아이콘(🐾📦🛖🗼🏰)과 거시(🌫️🌱🏘️🐾👑)는 시스템 상징으로 일관 사용. 카피 내 장식 이모지는 절제.

## 5. 디자인팀 전달 요약

- 이 카피는 **초안**. 화면 플로우·상태는 `기획-기능명세-v1.md` §2 참조.
- **말투 = 냥체**(고양이 대사 한정, 어미 '~냥' + 1인칭 '나'). 과한 아기말 금지, 버튼 라벨은 평어.
- 고양이: 1마리, 표정/상태 몇 개(상주/축하/안내/감정) + 커스터마이즈 색/무늬. 둥글고 따뜻, 앰버 기반.
- 등급 비주얼: 발자국→박스→작은집→캣타워→캣 팰리스. 모양+크기로 구분, 색은 앰버 고정(접근성).
- 톤: 심시티·경찰·감시 금지. 동물의숲/피크민 결.
- 확정 필요(→ 기획/CEO): 고양이 최종 승인, 정식 이름(가칭), 카피 최종 문구, **냥체 강도(현재 "어미+1인칭만" 수준) 최종 컨펌**.
