## 공통 헌법
- **완성도 = 깊이.** 성장 하나(고양이 동네 탐험·아지트 성장)를 안정적으로. 4기둥 재건축 아님.
- **재건축이 아니라 리스킨+정리.** 아래 재활용 자산 위에 얹는다.
- **세계관:** 동반묘(나=탐험자, 고양이=내 분신). 발자국→아지트 성장, 안개 탐험. 상세 `고양이-세계관-설계-v1.md`.
- **구현하지 말 것:** 모임 · DM/채팅 · 팔로우 · 점수판/랭킹/월간뱃지 · 퀘스트 · 스토리 · 남의 영역 보기(shared-map) · SNS 크롤 · 다묘/꾸미기 경제 · 프로필사진. (단, 관련 죽은 규칙·모델은 정리.)

## 1. 스택 승계 (짝 §1, §7)
Expo SDK54 / RN 0.81 / expo-router 6 / **Supabase(Postgres+PostGIS, Edge Functions)** / Zustand. 카카오맵은 **JS SDK를 WebView 주입**(react-native-maps 미사용 — 의존성 제거). 상세는 `기술-아키텍처-v1.md`(v0.2, Firebase→Supabase 전환).

## 2. 재활용 자산 (새로 만들지 말 것)
랜드마크 5단계 집계(`postAggregation` → 아지트 5단계로 경계 교체), 코스 추천/빈칸 채우기, 카카오맵 WebView 브리지+메시지 프로토콜, 저장 핀(→위시리스트), 인증(카카오 CF 커스텀토큰/구글 implicit/애플), 약관 3종+서버 재검증, 길찾기 프록시.

## 3. 부채 청산 (재개발의 핵심 — 짝 §9)
- **점수·성장 로직을 서버로 이동.** 클라이언트 성장 쓰기 금지, 보안 규칙 "본인/서버만 쓰기". `addScore(타인)`↔규칙 충돌(§9.1) 해소. 성장은 Supabase Edge Functions 트랜잭션 + Postgres 트리거로.
- **모임 `update` 전체 허용 등 광범위 규칙 제거**(모임 자체는 v1 OUT).
- **이미지 업로드 트랜잭션화** → 고아 게시물 제거.
- **거대 파일 분해**(index.tsx 2,326줄 등) → 컴포넌트/훅. **WebView HTML·마커 SVG를 공유 모듈로**(중복 정의 제거, 테마 팩 구조).
- 데이터 모델 정리: 좌표 **PostGIS `geography`**(GIST 인덱스), 문자열 좌표 폐기. 죽은 필드(`saved_places`,`points` 등) 제거.
- `users` 전체 공개 읽기 → 공개/비공개 프로필 분리(이메일 노출 방지).

## 4. 신규 구현 (v1 몸통)
- **지오펜스 도착 감지 + FCM 알림 파이프라인.** iOS "항상 허용" 권한 플로우(승낙률 병목 대비). 지오펜스 도착 알림만(소셜 알림 X).
- **GPS 근접 게이트 체크인**(반경 ~150m, 서버 재검증) → 1탭 아지트 성장.
- **아지트=장소 묶기**(도로명주소+좌표 근접 ~15m): 지도 단위=아지트, 방문 장소=입주 상점.
- **안개 탐험(fog of war):** geohash 셀 개척, 고양이는 걷힌 영역에서만 상주. 미시/거시 성장 + 서버 신뢰성. 감쇠 없음.
- **사진 기록 → 아지트 첨부**(트랜잭션), 아지트 상세=고양이의 추억.
- **고양이 커스터마이즈**(이름/외형 저장, 틴트 레이어).
- **위시리스트**(저장 핀 재활용, 크롤 없음), 코스 추천=고양이 산책 제안.
- 온보딩(카카오 1탭+약관+고양이 설정+내 동네+첫 발자국).
