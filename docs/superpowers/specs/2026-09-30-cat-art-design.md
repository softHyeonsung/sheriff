# 고양이 그림 교체 — 설계

> 2026-09-30 · ⑤ 온보딩·④ 지도 고양이에 이어서. 근거: `고양이-세계관-설계-v1.md`(동반묘·커스터마이즈 2~3종), 온보딩 `2026-09-29-onboarding-design.md`, 안개·고양이 `2026-09-29-fog-cat-design.md`

## 목표

임시 그림(한 장을 색만 바꾼 치즈·회색·까망)을 **사용자가 준 진짜 그림 세 마리**로 바꾸고, 지도·축하·온보딩에서 **자세**를 상황에 맞게 보여준다.

**성공 기준**
- 온보딩·프로필에서 **치즈 · 하양 · 고등어** 중 하나를 고른다.
- 지도 고양이는 걸을 때 걷는 자세, 멈추면 앉기, 한참 가만히 있으면 엎드리기, 누르면 2초 기뻐 뛰기.
- 축하 화면에 기뻐 뛰는 내 고양이.
- 프로필에서 고양이를 바꾸면 **지도 고양이도 바로** 바뀐다(지금은 앱을 다시 켜야 함 — 버그).
- 그림 주변의 반투명 부스러기·빛 번짐·크림색 배경 없이 깔끔하다.

## 그림 원본

| 고양이 | 앉기(단독) | 자세 모음(위 3: 앉기·걷기·엎드리기 / 아래 2: 기뻐 뛰기·뒤돌아보기) | 배경 상태 |
|---|---|---|---|
| 치즈 `cheese` | `1.png` | `11.png` | 투명, 반투명 부스러기 많음 |
| 하양 `white` | `2.png` | `22.png` | 투명, 넓은 흰 빛 번짐 |
| 고등어 `mackerel` | `3.png` | `고양이.png` | **불투명 크림색 배경** |

- 앉기는 단독 그림(크고 깔끔)을, 나머지 4자세는 자세 모음에서 쓴다.
- 원본은 `mobile/assets/cats/{cheese,white,mackerel}/`에 `sit.png`, `sheet.png`로 넣어 둔다(원본 보관, 다시 만들 수 있게).

## 결정 사항

| 결정 | 값 | 이유 |
|---|---|---|
| 고양이 종류 | `cheese` 치즈 · `white` 하양 · `mackerel` 고등어 | 사용자 결정. 색만 바꾼 회색·까망은 뺀다 |
| 기존 값 | `gray` → `mackerel`, `black` → `cheese` | 가장 가까운 그림. 프로필에서 다시 고를 수 있다 |
| 이름 | 코드는 `CatColor`·`catColor`·`cat_color` 그대로(값만 바뀜) | 바꿀 곳을 줄인다 |
| 자세 | `sit` 앉기 · `walk` 걷기 · `lie` 엎드리기 · `happy` 기뻐 뛰기 · `look` 뒤돌아보기 | 그림에 있는 다섯 |
| 없는 자세 | 그 고양이의 `sit`으로 | 그림을 빼먹어도 깨지지 않게 |
| 크기 | 긴 변 160px PNG(지도 48px × 3배 여유) | 앱 크기 |
| 배경 처리 | 투명 원본: 알파 40 미만 버림 + 작은 조각(면적 0.2% 미만) 제거. 하양 빛 번짐: 알파 150 미만 버림. 크림색 배경: 가장자리부터 비슷한 색(거리 18 이내)을 지워 나감 | 그림마다 상태가 달라서 |
| 자세 자르기 | 칸 위치(위 3칸·아래 2칸)로 자르고 여백 다듬기. 칸 안의 꽃잎·반짝이·"!"는 함께 | 세 장 배치가 같다 |
| 미리보기 | 15장을 한 장에 모은 `cats-preview.png`를 만들어 사용자가 보고 확인 | 자동 처리 결과를 사람이 본다 |

## 자세를 쓰는 곳

| 곳 | 자세 |
|---|---|
| 온보딩 환영 | `look`(뒤돌아보며 "같이 누벼볼까요?") |
| 온보딩 고양이 고르기 · 프로필 · 설정 | `sit` |
| 튜토리얼 3번째("뛰어놀 곳") | `walk` |
| 축하 화면 | `happy`(아지트 그림 옆에 작게) |
| 지도: 걸어갈 때 | `walk`(가는 방향으로 좌우 뒤집기, 지금처럼) |
| 지도: 멈춘 뒤 | `sit` |
| 지도: 멈춘 채 20초 | `lie` |
| 지도: 고양이를 누름 | `happy` 2초(말풍선과 함께) → 원래 자세 |

## 바뀌는 것

- **스크립트** `mobile/scripts/make_cat.py` 다시 쓰기: 원본 폴더 → 정리 → `src/map/cat-image.generated.ts`
  - `CAT_IMAGES: Record<CatColor, Record<CatPose, string>>`(data URI)
  - `--preview`로 `mobile/scripts/cats-preview.png`
- **`catColors.ts`**: 값·라벨(치즈·하양·고등어), `CatPose`, `catArt(color, pose)`(없으면 `sit`).
- **DB 마이그레이션**: `profiles_cat_color_check`를 새 세 값으로, 기존 값 옮기기, `save_cat` 검사 값 바꾸기.
- **지도**(`webview-template`·`protocol`·`MapBridge`): 설정에 고양이 자세 그림 묶음, `setCat` 메시지(고양이 바꾸면 그림 묶음 교체), 걷기·앉기·엎드리기·기뻐 뛰기 전환.
- **화면**: 환영·고양이 고르기·튜토리얼·축하·프로필이 `catArt`로.

## 테스트

- 스크립트: 원본 없이 돌리면 오류 안내, 자세 누락 시 `sit`으로 채움(작은 자체 검사).
- jest: `catArt` 대체 규칙, 온보딩·프로필 라벨 3종, 축하에 기뻐 뛰는 고양이, 지도 `setCat`(고양이 바뀌면 보냄), 페이지 스크립트 문법·자세 전환 함수 존재.
- pgTAP: `save_cat`이 새 값만 받고 옛 값(`gray`)은 거절, 옛 값 옮기기.
- 사람 확인: `cats-preview.png`로 15장 모양, 실기기에서 지도 고양이 자세 전환.

## 범위 밖

- 고양이 더 늘리기·무늬 섞기 — 그림이 더 오면.
- 여러 장으로 된 움직임(프레임 애니메이션) — 지금은 자세 전환만.
