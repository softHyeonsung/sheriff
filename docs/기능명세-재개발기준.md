**네비 가드(`_layout.tsx`):** 로그인 여부·`profile_complete`·폰트 3상태 확정까지 스피너 오버레이. 로그인 판정 = `firebaseUser || kakaoUser`. 카카오 uid = `kakao_{카카오ID}`, 화면마다 `firebaseUser?.uid ?? (kakaoUser ? 'kakao_'+id : null)` 반복(재개발 시 훅 통합 권장).

## 3. 기능 상세

### 3.1 인증
- 이메일: `createUser/signIn WithEmailAndPassword`, 비번 6자+, 닉네임 필수.
- 카카오: 시스템 브라우저 OAuth → 토큰 교환 → CF `kakaoCustomToken` → `signInWithCustomToken`. 유저 문서 upsert는 서버 전담. 세션 `expo-secure-store`.
- 구글: `openAuthSessionAsync` implicit `id_token`(nonce) → `signInWithCredential`. 정적 리다이렉트 `public/google.html`.
- 애플: `expo-apple-authentication`(iOS만) → `OAuthProvider('apple.com')`.
- **약관 3종(AUTH-06):** 이용약관/개인정보/위치기반. 이메일 가입 3개 전체 체크. 소셜은 기기당 1회(`terms_agreed_locally`). 서버 재검증: 신규+`agreedToTerms!==true`면 CF `failed-precondition`. 신규 문서에 `terms_agreed_at`, `location_consent:true`.
- 신규 유저 기본값: `points 0, sheriff_score 0, badge_list [], saved_places [], followers [], following [], blocked_users [], rank_level 'rookie', is_home_verified false, profile_complete false`.

### 3.2 온보딩 (`profile-setup`)
닉네임(≤20자) + 거주지역 3단(`KOREA_DISTRICTS` 266줄 정적). 저장 시 `nickname`, `home_address`(자기신고), `profile_complete:true`. ⚠️ `home_address`는 자기신고값(GPS 인증 `is_home_verified`와 별개), 월간 보안관 집계는 이 값만 봄.

### 3.3 지도 (`(tabs)/index.tsx`, 2,326줄 — 최대)
RN↔WebView 메시지 브리지. RN→웹: `SET_LOCATION, MY_LOCATION, CENTER, GO_TO, SET_MODE, SHOW_PLACE_MARKERS, CLEAR_PLACES, UPDATE_APP_PINS, SET_DRAGGABLE, DRAW_ROUTE, DRAW_ROUTE_SEGMENTS, CLEAR_ROUTE`. 웹→RN: `MAP_READY, MAP_CENTER, PIN_PRESS, PLACE_PRESS, MAP_PRESS, WV_ERROR`(타입가드). 초기 줌 5, 서울시청 중심.

**3모드:** 기본(게시물 핀+TourAPI 관광지, 진입 시 반경 2km 15개 1회) / 내 지도(저장 핀 초록) / 모임(모집중 가까운 15개+내 랜드마크, 카테고리 칩+검색). ※ CLAUDE.md의 Quest 탭 미구현, 대신 모임 모드.

위치: `expo-location` 포그라운드 → 1회 획득(실패 시 서울) → `watchPositionAsync`(Balanced, 10m/5초). 거부 시 `?? SEOUL` 폴백.

검색: Kakao `keyword.json`(반경 20km). 카테고리 칩 5종(FD6/CE7/CS2/SW8/PM9). 지역 이동 드롭다운(도→시군구→읍면동, `GO_TO` 줌 9/7/5). 결과 바텀시트.

길찾기(MAP-07): 자동차(CF `kakaoDirections`, 택시요금+경로 500꼭짓점) / 대중교통(CF `odsayDirections`, 환승·첫막차·구간색) / 도보(직선÷80m/분 추정 점선). 응답 경쟁 방지 `dirRequestId` 세대 토큰.

핀 저장(MAP-03/04): 1탭 → 로컬 즉시 + `users/{uid}/savedPins/{placeId}`(실패는 콘솔 경고만, 롤백 없음). 지도 공유: 전용 모달에서 채팅방 골라 `map_share` 메시지.

### 3.4 동네 연대기 — 방문 랜드마크 + 코스 추천 (`utils/postAggregation.ts`)
새 컬렉션·트리거 없이 `posts` 클라이언트 집계.
| 방문 횟수(같은 `location_pin.id`) | 등급 | 마커 |
|---|---|---|
| 1~2 | flag 깃발 | 24px |
| 3~6 | signpost 이정표 | 28px |
| 7~14 | house 집 | 32px |
| 15~29 | hotel 호텔 | 36px |
| 30+ | building 빌딩 | 40px |
색 앰버 고정, 모양+크기로 등급. 좌표 비정상/`location_pin` 없는 게시물 제외. 마커 SVG는 `index.tsx`와 `shared-map`에 **중복 정의**.

코스 추천("빈칸 채우기"): 랜드마크 → 현재 위치(없으면 서울) TourAPI 후보 → 내 랜드마크 50m 내면 `visited`(좌표 판정) → `buildCourse`(미방문 우선, 최근접, 최대 4) → 구간마다 `kakaoDirections` 앰버 실선. 🟡 출발점=현재 위치(선택 랜드마크 아님, id 체계 달라 비교 무효). 코스 1회=최대 4콜(일 50 한도 빨리 소진).

### 3.5 피드/게시물
작성: 본문 ≤500자, 사진 ≤5장, 해시태그 자동추출, 장소태그(`location_pin` 전체 저장). 저장순서: 문서 생성(`media_urls:[]`)→Storage 업로드→갱신(**중간 실패 시 이미지 없는 게시물 잔존, 트랜잭션 없음**). 점수: 하루 3회 +10, 장소태그 +5, 첫 게시물 뱃지. `type` 항상 `'feed'`, `author_is_sheriff` **항상 false**(§9).
피드: `posts` 전체 `timestamp desc` 실시간, 차단 제외, 클라 검색. 상세: 좋아요/댓글/팔로우/북마크/공유/미니맵/신고·삭제. 좋아요 = `likes:string[]` union/remove. 댓글 필드는 `text`(+`author_nickname, author_is_sheriff`).
점수: 좋아요받기 +2, 댓글받기 +3(+알림), 삭제 −10.

### 3.6 모임
생성: 일반/번개, 카테고리·제목(≤40)·소개·일시·장소·정원(2~20, 기본4 호스트포함). 일반=요일다중+시각 문자열, 번개=달력+시각+마감(`deadline_ms`). 개설 +20, `gathering_host` 뱃지. `meeting_at`은 **표시용 문자열**(파싱 안 함 → 정렬·알림·자동완료 불가).
목록: 카테고리+검색+거리순. 번개는 마감 지나면 목록에서 **숨김**(1분 재평가). 🟡 UI는 "자동 삭제"지만 실제 삭제 안 함. 참여 버튼: 신청→신청중→확정✓/거절/모집완료. 호스트: 승인/거절(사유), 삭제.
상세: 신청/승인/거절, 완료(+10)/취소(−20)/삭제. 승인 시 `participants` 추가+정원검사+채팅방 존재하면 arrayUnion+참여자 +15+뱃지+알림. ⚠️ 채팅방 "자동 생성" 아님(호스트 수동, 2명+ 시 버튼). ⚠️ `requested_at` 항상 '방금 전'. ⚠️ 수정 화면 없음, 승인 후 탈퇴 없음.

### 3.7 채팅
방: `dm`(`dm_`+정렬 두 uid) / `gathering`(모임 id). 목록 `members array-contains`, `last_message_at` 클라 정렬, 미읽음 배지. 전송 시 `last_message` 갱신+`unread_counts` +1. 진입 시 `markRoomAsRead`. 특수: `sender_id==='system'` 중앙정렬, `type:'map_share'` 카드→`/shared-map/{uid}`. 🟡 **유저 검색 버그:** `HIGH_SUFFIX=''`라 정확 일치만 검색.

### 3.8 프로필/소셜/뱃지
내 프로필: 닉네임(월간뱃지 시 방패)+등급칩+점수+통계3(저장/팔로워/팔로잉)+알림벨+설정. 하위탭 게시물/모임/뱃지. 점수모달: 내 활동 / 지역 랭킹. 🟡 "활동 내역" 점수는 화면 단순곱셈(`게시물×10+모임×15+저장×15+주거지50`)로 실제 `sheriff_score`와 다름. 🟡 "지역 랭킹"이 실은 **전국 TOP10**. ❌ 프로필 사진 변경(핸들러 없음).
주거지 인증(USER-04): GPS→Kakao `coord2regioncode`→확인→`verifyHome`(트랜잭션, 최초 +50, `home_verified` 뱃지, `home_location` GeoPoint).
팔로우: 내 `following`+상대 `followers` arrayUnion(원자 아님).
뱃지 카탈로그: 점수(100/300/600/1000/2000), 활동(첫게시물/저장5/모임개최/참여/주거지), 월간(`sheriff_YYYY_MM`).

### 3.9 보안관 시스템 (점수·등급·월간)
점수표: 게시물 +10(일3)/장소태그 +5/삭제 −10/좋아요받기 +2/댓글받기 +3/장소저장 +5(일5)/전체최초저장 +15/최초저장자 +3/주거지 +50/모임개설 +20/참여승인 +15/완료 +10/취소 −20/퀘스트 +30(❌). 0 미만 불가. 등급: 새내기(0)→동네주민(100)→단골(300)→터줏대감(600)→인플루언서(1000)→후보(2000). 일일 한도 `daily_stats/{YYYY-MM-DD}`(UTC). 서버 `onScoreUpdate` 마일스톤 뱃지 이중화.
월간 보안관(`monthlySheriffBadge`, 매월1일 00:00 KST): 전 유저 `sheriff_score desc`, `home_address` 정규식으로 지역 그룹→지역 TOP10에 직전달 뱃지 arrayUnion. 🟡 전 유저 단일 batch(500 한도·비용). 🟡 정규식 `(\S+구|\S+군|\S+시)`가 첫 매치 반환 → "서울특별시 종로구"는 "서울특별시"가 잡혀 서울 전체가 한 지역. 재개발 시 행정구역 파서 별도.

### 3.10 신고/차단
신고: 게시물/유저, 사유 4종 → `reports`(`status:'pending'`, 클라 읽기·수정·삭제 불가). 차단: `blocked_users` 배열 → 피드·지도 게시물만 필터. 🟡 댓글·모임·채팅엔 차단 필터 없음.

### 3.11 알림 (앱 내)
`users/{uid}/notifications`, 4종(`join_request/join_approved/join_rejected/comment`). 클라가 상대 서브컬렉션에 직접 write(규칙이 create 허용). ❌ FCM 푸시, 좋아요/팔로우/채팅 알림 없음.

### 3.12 지도 공유 / 타인 지도 (`shared-map/[uid]`)
타 유저 저장 핀(초록)+랜드마크(`author_id==uid` 구독). `setBounds`. 빈 상태는 핀0 AND 랜드마크0. 보안: 주입 JSON `<`→이스케이프, InfoWindow `escapeHtml` — **재개발 시 승계**. ❌ 나란히 비교 뷰(후속).

## 4. 데이터 모델 (실제 사용)

## 9. 문서↔코드 불일치 & 결함 (재개발 시 결정)
### 9.1 동작 안 하거나 의도와 다름
1. **점수 지급 vs 규칙 충돌(최중요, 추론):** `addScore(타인uid)`가 규칙(본인 외 `followers`만)과 충돌. 좋아요/댓글받기·모임 참여+15·최초저장+3·마일스톤 뱃지가 `.catch(()=>{})`로 **조용히 실패** 가능. 재개발 시 점수 집계 CF로 이관.
2. **보안관 금색 강조 미작동:** `author_is_sheriff`/`host_is_sheriff` 항상 false 저장. 월간 뱃지 받아도 카드 금테 안 뜸. `badge_list` 조회하거나 서버 채움 필요.
3. **클라 점수 조작 가능**(본인 문서 write).
4. **이미지 실패 시 고아 게시물**, 다단계 쓰기 트랜잭션 없음.
5. **유저 검색 정확 일치만**.
6. **번개 삭제 아니고 숨김**.
7. **모임 채팅방 수동 생성**.
8. **코스 출발점 = 현재 위치**.
9. **"지역 랭킹"이 전국**, 활동 내역 점수 임의 계산.
10. **차단 게시물만 필터**.
11. **프로필 사진 변경 없음**.
12. 완료/취소 모임 status 필터가 지도 `recruiting`에만.
### 9.2 CLAUDE.md엔 있으나 코드에 없음(❌)
