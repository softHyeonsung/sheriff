## 0. "완성도"의 정의 — 이 문서의 헌법

**완성도 = 기능의 넓이가 아니라 한 축의 깊이.**
성장 **하나**를, 낯선 사람이 스토어에서 받아 써도 "이거 잘 만들었다" 소리가 나오게 마감한다. 네 개를 어중간하게가 아니라, 한 개를 진짜 좋게.

**한 줄 제품:** 너와 너의 고양이가 진짜 동네를 탐험하며, 다닌 곳에 아지트를 지어간다. 혼자 써도 값어치가 난다.

---

## 1. Definition of Done — 이게 다 되면 출시

1. 낯선 사람이 받아서 **2분 안에** 온보딩을 마치고, 그 끝에 **첫 발자국을 찍어 첫 아지트가 지도에 생겨** 있고, 루프를 이해한다.
2. 핵심 루프(도착→알림→체크인→성장→축하)가 **안정적으로** 돌고, GPS 오차·권한 거부·오프라인이 앱을 깨지 않고 우아하게 처리된다.
3. **아무것도 안 해도** 집에서 앱을 열면 내 영역·고양이·아지트 이야기가 있어서 볼 맛이 난다(수동적 즐거움).
4. 막다른 화면, 텅 빈 슬픈 화면, 눈에 띄는 버벅임이 없다.
5. 스토어 제출 가능(약관 3종·심사물·아이콘·스크린샷·개인정보 처리방침 완비).

---

## 2. IN — 출시 필수 (이게 v1의 몸통)

**온보딩·첫인상**
- 위치·알림 권한 요청(설치=위치 동의 전제), 내 동네 설정, **고양이 이름/외형 정하기**.
- 온보딩 끝에 **첫 발자국/첫 아지트**를 찍게 해서, 끝나는 순간 지도가 비어 있지 않게.
- 루프를 가르치는 짧고 즐거운 튜토리얼.

**핵심 루프**
- 지도 = 내 영역(홈 화면), 따뜻한 렌더 + **고양이(동반묘) 상주**.
- 발자국 체크인: GPS 근접 게이트(반경 ~150m) → 1탭 → 아지트 성장 + 축하 연출.
- 지오펜스 도착 알림 → 알림에서 바로 체크인.
- 선택적 "순간 남기기 📷" → 사진이 아지트에 붙어 **아지트 상세=고양이의 추억**.

**성장·시각 (세계관: `고양이-세계관-설계-v1.md`)**
- 미시 5단계: 🐾발자국→📦박스→🛖작은 집→🗼캣타워→🏰캣 팰리스. 모양+크기로 구분, 따뜻한 팔레트.
- 거시 = **안개 탐험(fog of war)**: 발자국으로 안개가 걷히고 고양이 무대가 넓어진다. 개척률 X%. **감쇠 없음.**
- 고양이: 걷힌 영역 상주·성장 축하·미개척지 안내(=코스 추천 재활용)·감정 상태.

**계정·약관 (스토어 필수)**
- 카카오 중심 로그인 + 약관 3종(이용/개인정보/위치) — 기존 코드 승계.
- iOS: 다른 소셜 로그인이 있으면 **애플 로그인 필수** → 애플/구글 유지.

**안정성·성능 (재개발이니 정리)**
- 이미지 업로드 트랜잭션화(고아 게시물 버그 제거, 짝 §9.1).
- 성장·데이터 쓰기 신뢰성(클라이언트 조작·규칙 충돌 정리, 짝 §9.1).
- 거대 파일 분해(index.tsx 2,326줄 등, 짝 §9.4).

**스토어 준비**
- 앱 아이콘, 스플래시, 스토어 스크린샷·설명, 개인정보 처리방침 페이지.

---

## 3. IN — 넣되 가볍게 (완성도를 위해)

- **가고 싶은 곳(위시리스트) = "고양이가 찜한 곳":** 앱 내 검색으로 찜 → 지도에 별도 핀. **SNS 크롤 자동수집은 제외**(로드맵). 기존 저장 핀 재활용.
- **코스 추천/빈칸 채우기 = "고양이가 가보고 싶어하는 곳":** 재방문 훅. 기존 코드 재활용.
- **고양이 커스터마이즈:** 이름 + 색/무늬 2~3종. 애착 상승, 비용 작음. 깊은 꾸미기는 로드맵.

## 4. OUT — v1 아님 (로드맵) + 이유

| 제외 | 이유 |
|---|---|
| 모임(일반/번개) | 밀도 필요. 0명에서 텅 빔 |
| 점수판/등급 랭킹/월간 뱃지 | 별도 점수 시스템 불필요 — **성장(아지트·영역) 자체가 진행 시스템** (§5) |
| DM/채팅 · 팔로우 | 상대 필요 |
| **남의 영역/고양이 방문(shared-map)** | 코드는 있으나 0명에선 빈 화면. **출시 직후 첫 확장 1순위** |
| SNS 크롤 자동수집 | 깨지기 쉬운 대공사 + 차별성 아님. 검증 후 |
| 다묘 입양 · 아지트 꾸미기 경제 | 로드맵(현실 탐험 보상으로 연결, 세계관 §7) |
| 퀘스트 · 스토리 · 프로필 사진 · 지도 3분할 | 웨지와 무관 / 영역-우선 1~2모드로 대체 |

## 5. 정체성 처리 — 별도 점수판은 없다

별도 점수 원장을 두지 않는다. **진행(progression)은 아지트 레벨업과 영역(안개) 확장 그 자체.** "이 동네를 개척한 나의 고양이"라는 정체성은 성장으로 표현되고, 이름은 별도 트랙에서 따뜻하게 확정(가칭 진행).
