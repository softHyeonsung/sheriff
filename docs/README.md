# 산책냥(구 보안관) — 개발 문서 번들 (v1)

> 정리일: 2026-09-22 · 출처: claude.ai 프로젝트 "sheriff" 문서 스냅샷
> 이 폴더(`docs/`)는 **v1 재개발에 필요한 문서 모음**입니다. 세계관은 **고양이(동반묘)**로 통일돼 있습니다.

## 한 줄 제품
너와 너의 **고양이**가 진짜 동네를 탐험하며, 다닌 곳에 **아지트**를 지어간다. 안개가 걷히며 영역이 넓어진다. 혼자 써도 값어치가 난다. (동네판 스트라바 + 코지 게임)

## 읽는 순서 (개발자 기준)

1. **`v1-제품방향-결정기록.md`** — 왜 이 스코프인가(전략·컨텍스트). *※ 원본 전략 기록이라 표기는 고양이 재테마 이전(건물/마을) — 세계관은 아래 세계관 문서가 최신.*
2. **`출시용-v1-범위정의.md`** — 무엇을 만들고(IN) 무엇을 빼는가(OUT). 출시 판정 기준(DoD). **범위의 헌법.**
3. **`고양이-세계관-설계-v1.md`** — 세계관 캐논(동반묘·성장 사다리·안개 탐험·커스터마이즈·로드맵).
4. **`기능명세-재개발기준.md`** — 현행 코드 전수분석. **재활용/제거/부채를 여기서 파악.** (분량 큼, 필독)
5. **`기술-아키텍처-v1.md`** — 스택·시스템 구성·모듈 구조·서버 설계·데이터 모델·보안 규칙·CI. **개발 설계의 중심.**
6. **`기획-기능명세-v1.md`** — 화면별 플로우·상태·엣지케이스 + 성장 규칙(임계값) + 정책.
7. **`기획-지표-DoD-v1.md`** — 심을 측정 이벤트 스펙 + DoD 게이트 운영.
8. **`기획-카피톤-v1.md`** — 카피·마스코트(고양이) 말투. UI 문구.
9. **`핸드오프-개발팀-v1.md`** — CEO의 개발 착수 지시(요약 브리프).
10. **`DESIGN.md`** — 디자인 시스템(시맨틱 토큰·타이포·모션). *※ 레포 루트에도 DESIGN.md + design-tokens.css 있음(구현 연동).*

## 성장 사다리 (미시 · 아지트)
🐾 발자국(1) → 📦 박스(2~4) → 🛖 작은 집(5~9) → 🗼 캣타워(10~19) → 🏰 캣 팰리스(20+). 모양+크기로 등급 구분, 색은 앰버 고정.

## 거시 (안개 탐험)
발자국으로 안개(geohash 셀)가 걷히고 고양이 무대가 넓어짐. 🌫️안개 낀 골목 → 🌱개척지 → 🏘️아늑한 동네 → 🐾고양이 영역 → 👑고양이 왕국. 감쇠 없음.

## 착수 우선순위 (기술-아키텍처 §10)
P0: 성장 로직 서버 이관 + RLS 정리 · 데이터 모델 PostGIS `geography` + 공개/비공개 분리 · 이미지 업로드 트랜잭션화.
P1: 거대 파일 분해·공유 모듈화 · 지오펜스+FCM+근접 게이트 · 안개 탐험+거시 진화.

성장 곡선 확정 수치(파일럿 튜닝) · iOS "항상 허용" UX · 재방문 발자국 간격.
