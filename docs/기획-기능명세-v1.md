## 0. 헌법
- **완성도 = 깊이.** 성장 하나를 낯선 사람이 "잘 만들었다" 할 만큼.
- **한 줄 제품:** 너와 너의 고양이가 진짜 동네를 탐험하며, 다닌 곳에 아지트를 지어간다.
- **세계관:** 동반묘(나=탐험자, 고양이=내 분신/아바타). `고양이-세계관-설계-v1.md`.
- **핵심 루프:** 도착 → 지오펜스 알림 → 근접 게이트(~150m) → 1탭 발자국 → 아지트 성장 + 축하 → (선택) 순간 남기기 📷.
- **범위 밖:** 모임 · 점수판/랭킹/월간뱃지 · DM/채팅/팔로우 · 남의 영역 보기 · SNS 크롤 · 다묘/꾸미기 경제 · 퀘스트/스토리/프로필사진 · 지도 3분할. 알림은 **지오펜스 도착 알림만**.

**용어**
- **발자국:** 아지트 근처 1탭 방문 기록 = 고양이 발바닥. 성장 원자 단위.
- **아지트:** 지도 위 성장 단위(도로명주소+좌표로 묶인 물리적 건물).
- **내 영역:** 아지트 집합 = 홈. 안개 걷힌 만큼 고양이가 노는 영역.
- **고양이(동반묘):** 나의 분신. 상주·축하·안내·감정. 커스터마이즈(이름+색/무늬).
- **성장:** 미시(아지트 5단계) + 거시(안개 탐험). 별도 점수 없음.

## 1. 화면 목록 & IA
지도 3분할 폐기 → **내 영역-우선 1~2모드**. 탭 최소화.
```
app/
├─ login             카카오 1탭 + 약관 3종 (iOS 애플 필수)
├─ onboarding        권한 → 고양이 이름/외형 → 내 동네 → 튜토리얼 → 첫 발자국
├─ (tabs)/{map,profile}      map=내 영역(홈, 고양이+안개), profile=최소 설정
├─ aidut/[id]        아지트 상세 = 고양이의 추억(사진)
├─ checkin           발자국 체크인 시트
├─ wishlist          고양이가 찜한 곳
└─ course            코스 = 고양이의 산책 제안
```
탭 = 지도/프로필 2탭. 나머지는 스택.

## 2. 화면별 명세 (목적→플로우→상태→엣지)

### 2.1 로그인
카카오 1탭 중심 + iOS 애플 필수 + 구글 유지. 약관 3종(신규 전체 동의, 기기당 1회 캐시, 서버 재검증). 엣지: OAuth 취소/네트워크/애플 누락/약관 일부 → 각각 우아 처리, 크래시 금지.

### 2.2 온보딩 — 2분 내 + 끝에 첫 발자국
플로우: 환영 → **고양이 정하기(이름+색/무늬)** → 위치 권한 → 알림 권한(iOS Always 강요 금지) → 내 동네(GPS 자동추정+수정) → 튜토리얼 3컷 → **첫 발자국(🐾 + 주변 안개 걷힘 + 축하)**. 완료 시 `profile_complete`.
엣지: 위치/알림 거부 시 진행 허용+수동 대체, GPS 실패 시 수동 동네, 후보 없으면 현재 좌표 독립 아지트(빈 지도 금지), 중단 시 마지막 단계부터.

### 2.3 지도 = 내 영역 (홈)
모드 토글 [내 영역 | 탐색]. 내 영역 = 아지트 마커 + **안개(미개척)** + 걷힌 영역 도는 고양이 + 찜 핀. 탐색 = 검색·주변 후보(찜/코스). 3모드 중 모임 제거, 게시물 핀 제거.
엣지: WebView 로드 실패 재시도, 오프라인 캐시 렌더+배지, 위치 없음 안내 배너.

### 2.4 아지트 상세 = 고양이의 추억
헤더(이름·등급 🐾~🏰·발자국 수·다음 단계 힌트) + 사진 이야기(시간순) + 테넌트 목록. 근접 안일 때만 추가 활성. 사진 0 → 긍정 빈 상태.

### 2.5 발자국 체크인 (심장박동)
알림/근접 진입 → **근접 게이트(~150m)** → 시트("한 번 더 오면 ○○") → [발자국 꽂기](성장+축하+안개 걷힘) / [순간 남기기 📷](선택).
⭐ 엣지(안정성): 근접 밖 비활성, GPS 실패 무근거 성장 금지, 같은 아지트 쿨다운, 사진 실패는 트랜잭션 재시도 큐(고아 방지), 오프라인 큐잉+낙관 UI+롤백.

### 2.6 코스 = 고양이의 산책 제안
고양이 힌트/탐색 진입 → 주변 후보(TourAPI) → 미방문 우선 최대 4곳 → 앰버 실선. 후보 0="다 개척했어요". 길찾기 일 50콜 한도(임박 시 핀만, 리셋 KST 09:00). 출발점=현재 위치(명시).

### 2.7 위시리스트 = 고양이가 찜한 곳
앱 내 검색 → 찜 → 별도 색 핀(저장 핀 재활용). 방문 시 아지트 성장 = "달성". SNS 크롤 제외.

### 2.8 프로필/설정 (최소)
고양이(이름/외형 변경) · 내 동네 · 알림 설정 · 로그아웃 · 계정(탈퇴/약관). 소셜/뱃지/랭킹/다묘/꾸미기/프로필사진 없음.

## 3. 정책 · 엣지 (전역)

**3.1 알림 = 지오펜스 도착만.** 트리거: 내 아지트/찜 진입. 쿨다운 6h·일 8회·야간DND 22~08·2분 체류(초안). iOS Always 병목=초기 지표.
**3.2 권한 거부:** 위치/알림/iOS Always 각각 우아 축소 동작 + 재요청 배너. 앱 안 깨짐.
**3.3 GPS:** 반경 ~150m 관대, accuracy>150m 보류, 타임아웃 무근거 성장 금지. 위치 조작 방지 v1 버림.
**3.4 오프라인:** 캐시 렌더+배지, 체크인 로컬 큐잉+낙관 UI+롤백, 사진 큐 업로드.
**3.5 빈 상태:** 막다른/슬픈 화면 금지. 모두 고양이 + 다음 CTA.
**3.6 안정성:** 성장 쓰기 서버 권위, 이미지 트랜잭션화, 거대 파일 분해.

## 4. 성장 규칙 (수치 초안 — 파일럿 튜닝, 서버 상수화)

**4.1 미시 — 아지트 5단계**
| 발자국 | 등급 | 아이콘 |
|---|---|---|
| 1 | 발자국 | 🐾 |
| 2~4 | 박스 | 📦 |
| 5~9 | 작은 집 | 🛖 |
| 10~19 | 캣타워 | 🗼 |
| 20+ | 캣 팰리스 | 🏰 |
모양+크기 구분(색 앰버 고정). `postAggregation` 경계(1~2/3~6/7~14/15~29/30) **교체**. 감쇠 없음.

**4.2 발자국 카운팅:** 근접 통과 1탭 = 1발자국. 같은 아지트 재방문 최소 6시간 또는 하루 1회(파일럿 결정). 사진은 발자국과 독립.

**4.3 거시 — 안개 탐험 + 영역 진화**
안개 걷힘(발자국 셀만 컬러화, 고양이는 걷힌 영역에서만). 개척률 X%. 동 단위 진화(초안):
| 단계 | 조건(초안) |
|---|---|
| 🌫️ 안개 낀 골목 | 아지트 0~2 |
| 🌱 개척지 | 3~7 |
| 🏘️ 아늑한 동네 | 8~15 |
| 🐾 고양이 영역 | 16~30 |
| 👑 고양이 왕국 | 31+ |

**4.4 아지트=장소 묶기:** 도로명주소+좌표 근접 ~15m, 애매하면 독립. 테넌트 층별 표시. 비정상 좌표 집계 제외.

## 5. 구현 메모 (개발)
- **재활용:** 랜드마크 5단계 집계, 코스 추천, 카카오맵 브리지, 저장 핀, 카카오 로그인+약관.

- **제거:** 피드·모임·채팅·팔로우·랭킹·뱃지·점수판·남의 영역·게시물 핀·모임 모드.
