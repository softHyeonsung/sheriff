## 해야 할 일

### 사람이 직접 (코드로 못 함)
1. 카카오 디벨로퍼스 → 플랫폼 → **Web**에 `http://localhost` 등록 (지도용)
2. 발자국·박스 이미지 **상업적 사용 라이선스** 확인
3. **행정동 경계 데이터** 받기(github.com/vuski/admdongkor 최신 GeoJSON) + 출처 표기·라이선스 확인 → 넣기:
   `python supabase/scripts/load_admin_dongs.py <파일> supabase/.admin_dongs.sql` 후
   로컬 `Get-Content supabase/.admin_dongs.sql -Raw -Encoding UTF8 | docker exec -i supabase_db_sanchaeknyang psql -U postgres -d postgres`
   (넣기 전엔 동네 배지가 안 보이고 체크인은 정상)
4. 🐈 그림을 바꾸거나 고양이를 늘리려면 `mobile/assets/cats/{고양이}/sit.png·sheet.png` 넣고 `python mobile/scripts/make_cat.py --preview`
5. **Supabase 무료 요금제**: 1주일 안 쓰면 프로젝트가 멈춤(대시보드에서 Resume). 파일 저장 1GB ≈ 사진 5천 장(200KB). 출시 전 요금제 결정
6. **TourAPI**: 출처 표기 조건 확인(지금은 카드에 "장소 정보: 한국관광공사"), 배포할 때 Supabase 시크릿에 `TOURAPI_KEY` 넣기. 카카오 모빌리티 길찾기는 **자동차 길 기준**이라 선이 실제 걷는 길보다 크게 돌아갈 수 있음(광화문 실측: 직선 합 0.7km인 코스의 자동차 길 4.8km) — 걷는 길이 필요하면 티맵 보행자 경로로 교체

### 실기기 확인 (Android dev build)
준비:
- Docker Desktop 켜기 → `npx supabase start`
- `npx supabase functions serve --env-file supabase/functions/.env.local` (켜둔 채로 — 탈퇴 `delete-account`·코스 `suggest-course`도 같이 뜬다)
- `mobile/.env.local`의 `EXPO_PUBLIC_SUPABASE_URL`을 PC 내부 IP로(`ipconfig`의 IPv4, 예: `http://192.168.0.12:54321`), 폰과 PC 같은 와이파이
- `cd mobile && npx expo run:android` (새 네이티브 모듈: WebView·위치·햅틱·**알림(⑤에서 추가)**·**지오펜스(⑥-1에서 추가 — task-manager·백그라운드 위치, dev build 다시 필요)**·**연결 감지(⑥-2 expo-network)**·**사진(⑥-3 image-picker·image-manipulator)**·**공유 받기(⑥-5 expo-share-intent — iOS 공유 확장 포함, 서명에 App Group이 필요할 수 있음)**)
- 키 해시 카카오 콘솔 등록: `keytool -exportcert -alias androiddebugkey -keystore mobile/android/app/debug.keystore -storepass android | openssl sha1 -binary | openssl base64`

확인할 것(중요한 순):
1. **iPhone에서 발자국 뒤 축하 화면이 뜨는지** (자동 테스트로 못 잡은 부분 — 안 뜨면 시트와 축하를 한 Modal로 합치는 수정 필요)
2. 지도가 그려지는지, 카카오 로고 눌러도 지도 유지되는지 (iPhone에서 지도 일부가 막히면 허용 목록에 카카오 주소 추가)
3. 신규 카카오 계정 로그인 → 약관 시트 → 동의 → 지도
4. 실제 장소에서 발자국 → 축하 → 마커 변화, 바로 다시 → 쿨다운 안내, 멀리서 → "조금만 더 가까이"
5. 안개가 지도를 덮고 발자국 칸만 뚫리는지(줌·이동 시 따라오는지), 고양이가 걷힌 칸 안에서만 걷는지·누르면 말풍선, 동 배지가 지도를 멈출 때 바뀌는지, 칸 수백 개에서 버벅임, 붙어 있는 걷힌 칸 사이에 가는 안개 줄이 보이는지(보이면 칸 모서리 4점을 그대로 보내는 수정)
6. 온보딩: 권한 팝업 순서·거절해도 진행, 키보드가 이름·동네 입력을 가리지 않는지, 동네 추정이 맞는지, 첫 발자국 후 지도에 안개가 걷혀 있는지, 도중에 앱을 껐다 켜면 이어지는지, 로그인 직후 "카카오 로그인 실패" 로그가 뜨지 않는지(뜨면 login.tsx의 router.replace 제거)
7. 도착 알림: 재방문 축하 뒤 카드 한 번만, 좋아요 → 항상 허용 팝업(안드로이드는 설정 화면), 앱 끈 채 아지트 도착 2분 → 알림, 1분 만에 떠나면 알림 없음, 알림 탭 → 체크인 시트, 밤 10시 이후엔 안 옴
8. 오프라인: 비행기 모드로 발자국 → "챙겨뒀어요" → 비행기 모드 끄기 → 축하, 비행기 모드로 앱 켜기 → 마지막 지도+배지, 멀리서 챙긴 발자국 → 연결 후 "남기지 못했어요", 온보딩 첫 발자국을 오프라인에서 → 다음으로 넘어감
9. 순간 남기기: 축하 화면·상세에서 찍기/고르기 → 상세에 보이는지, 비행기 모드에서 남기고 연결 후 올라가는지, 멀리서 상세 버튼 비활성, 사진 크게 보기, 권한 거절 시 설정 안내
10. 프로필: 새 계정 온보딩에서 닉네임 추천·🎲·중복 안내, 고양이 색 바꾸고 지도 확인, 도착 알림 끄고 아지트 근처에서 알림 없는지, 탈퇴 후 같은 카카오로 다시 가입하면 약관부터
11. 위시리스트: 검색해 찜 → ⭐ 핀, 네이버지도·카카오맵·인스타에서 [공유 → 산책냥] → 후보 → 찜, 링크 붙여넣기, 찜한 곳 도착 알림 문구, 찜한 곳 발자국 → 축하 "드디어 왔어요" + 핀 사라짐
12. 고양이: 지도에서 걷기·앉기·엎드리기 전환, 누르면 기뻐 뛰기, 프로필에서 하양으로 바꾸고 지도 돌아오면 바로 하양, 축하 화면 기뻐 뛰는 고양이
13. 장소별 기록: 아지트가 있는 건물에서 다른 가게를 골라 발자국 → 아지트는 그대로, 상세 "여기서 간 곳"에 그 가게가 따로 세어지는지, 그때 찍은 사진을 크게 보면 그 가게 이름이 나오는지
14. 코스: [🐾 산책] → 번호 핀·주황 선이 안개 위로 보이는지, 코스 전체가 화면에 들어오는지(카드에 가리지 않는지), 카드 [⭐ 찜] → ⭐ 핀, 못 찾는 곳 → [찜 화면에서 찾기], 아지트 카드를 열었다 닫으면 코스 카드가 돌아오는지, 선이 실제 걷는 길과 얼마나 다른지
