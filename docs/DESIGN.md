## 0. 헌법 (변경 시 CEO 승인)
- **완성도 = 깊이.** 성장 하나(고양이 동네 탐험·아지트 성장)를 "잘 만들었다" 할 만큼.
- **세계관:** 너와 **고양이(동반묘)**가 진짜 동네를 누비며 아지트를 짓고, 안개가 걷히며 영역이 넓어진다.
- **톤:** 동물의숲/피크민 결 = 낮은 채도 · 자연 파스텔 · 넓은 여백.
- **브랜드색:** "앰버 포인트 + 자연(세이지) 베이스" — ✅ CEO 승인(09-22).
- **금지:** 심시티·경찰·감시 이미지. 채도 높은 색 전면.
- **형태:** 둥근 코너·둥근 형태 우선.

### 0.1 트렌드 가드레일
1. 차별화는 색이 아니라 **아트**로(고양이·아지트 성장 아트).
2. 세이지 채도 유지(`#9FBF9C`) + **CTA 앰버 고채도** 살려 밋밋함 방지.

## 1. 컬러 시스템

### 1.1 구조 원칙
- **시맨틱 토큰만.** raw hex 금지, `color/*` 참조. → 출시 후 맞춤 색상·**테마 팩(다른 세계 스킨)** 교체 대비.
- **에셋은 틴트 가능하게.** 아지트·고양이는 모노 베이스 + 틴트 레이어(고양이 털색·테마 팩 반응).
- **대비:** ink-on-surface ≥ 7:1.

### 1.2 코어 토큰 (기본 테마 "앰버 마을")
| 토큰 | 값 | 용도 |
|---|---|---|
| `color/surface` | `#FBF6EC` | 화면 바탕 |
| `color/surface/card` | `#FFFFFF` | 카드·시트 |
| `color/primary` | `#E6A552` | 브랜드 포인트·CTA |
| `color/primary/deep` | `#C98A3C` | 강조 |
| `color/nature` | `#9FBF9C` | 자연 베이스(지도·성장 긍정) |
| `color/nature/deep` | `#6E8F6B` | 자연 강조 |
| `color/fog` | `#D9D2C4` | **미개척 안개** |
| `color/sky` | `#BFD8DF` | 보조 |
| `color/ink` | `#4A3D30` | 본문 |
| `color/ink/sub` | `#8A7A68` | 보조 글자 |
| `color/line` | `#ECE3D2` | 구분선 |

### 1.3 프리셋 테마 (출시 후 · 미리 확보)
큐레이션 프리셋(자유 hex 아님, 대비 보호). 앰버 마을(기본)/세이지 숲/노을/저녁(다크 겸). v1은 기본 테마 + 토큰 구조만.

### 1.4 아지트·고양이 색 — 미정 (asset-first)
에셋 먼저 → 완성 아트에서 색 추출 → 테마별 매핑. 등급 구분 주 수단 = 모양+크기. 고양이 털색/무늬는 커스터마이즈(틴트).

## 3. 시각 언어 (잠정 · 시안 보고 조정)
- **형태:** 카드 16 · 버튼 12 · 바텀시트 24 · 칩/아바타 full · 최소 8. 직각 금지.
- **여백(4pt):** 거터 20 · 섹션 24 · 최소 8.
- **그림자:** 검정 금지. 웜 소프트 `y6 blur16 rgba(74,61,48,0.08)`.
- **모션:** 전환 200~250ms ease-out. **성장 축하=정점**(스프링 팝+소프트 파티클 ~600ms+햅틱). **고양이 idle: 걷힌 영역 어슬렁 bob.** **안개 걷힘: 발자국 시 페이드 아웃.**
- **아이콘:** 라운드 캡 2px, 일관 세트.
- **일러스트/고양이:** 플랫 코퍼릿 금지. 둥근 실루엣 + 수채/크레용 텍스처. 빈 상태는 고양이가 초대.

## 4. 핵심 아트 자산 (asset-first)
- **고양이(동반묘) 1마리:** 상태 4종+(등장/축하/안내/감정: 신남·심심) + idle. 커스터마이즈 털색/무늬 2~3종(틴트). "동네 짝꿍" 인상.
- **아지트 5단계:** 🐾발자국→📦박스→🛖작은 집→🗼캣타워→🏰캣 팰리스. 모양+크기 구분.
- **안개(fog of war):** 미개척=`color/fog`, 발자국 시 걷혀 컬러로.
- **거시 진화:** 🌫️안개 낀 골목→🌱개척지→🏘️아늑한 동네→🐾고양이 영역→👑고양이 왕국.
- 지도 SVG(고양이·아지트·안개)는 **한 모듈 공유 + 테마 팩 구조**(중복 정의 금지).
