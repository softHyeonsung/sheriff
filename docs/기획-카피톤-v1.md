## 0. 톤 헌법 (한 문장)

**다정한 고양이가 나와 함께 동네를 누비며 조용히 응원한다.** 감시하지 않고, 조르지 않고, 축하한다.

- 결: 동물의숲 / 피크민 블룸. 심시티·경찰·감시 **아님**(결정기록 §3).
- 동사: "짓다(construction)" ❌ → **"가꾸다·키우다·자라다·누비다"** ⭕.
- 화자: **내 고양이(동반묘)** — 나의 짝꿍. 함께 다니는 친구 말투. **다정한 해요체.** 과한 아기말·"~냥" 남발 금지(절제된 고양이 느낌만).

---

## 1. 절대 금지 (감시 어감 차단)

| 금지 | 이유 | 대체 |
|---|---|---|
| "보안관/경찰/순찰/감시/추적/동선" | 감시 불안 | "다녀온 곳", "발자국", "우리가 누빈 곳" |
| "당신을 감지했습니다", "위치가 확인됨" | 시스템·감시 톤 | "○○ 오셨네요" |
| "점수 획득 +10", "랭킹 3위" | 점수판 없음 | 성장 자체로("작은 집이 됐어요") |
| "미션 실패", "벌점", "감쇠" | 벌주지 않음 | 긍정만 |
| "체크인 안 하면 놓쳐요" (FOMO) | 조르는 톤 | 부드러운 초대 |
| 딱딱한 명령형("~하시오") | 차가움 | 청유·제안형("~해볼까요") |

## 2. 고양이 말투 (Voice)

**성격:** 다정하고 느긋한 내 짝꿍 고양이. 재촉하지 않고, 내가 뭘 하든 반겨준다. 작은 것도 같이 기뻐하고, 안 가본 골목을 궁금해한다.

**규칙**
- 다정한 **해요체**. 이모지 절제(문장당 최대 1개).
- 짧게. 한 번에 1~2줄.
- "우리 동네", "여기", "또 왔네요", "같이 가볼까요" — 함께함·소속감·재방문.
- 사람을 주어로("당신이 이만큼 누볐어요").
- 고양이는 **딱 1마리**, 상태 몇 개(등장/축하/안내/감정). 도감식 수집 금지.

**예시**
- 상주: "우리 동네, 오늘도 조용하고 좋네요."
- 미개척 유도: "저쪽 골목은 아직 안개예요. 같이 가볼까요?"
- 성장 축하: "여기, 이제 작은 집이 됐어요 🛖"

## 3. 상황별 카피 (샘플 — 초안)

### 3.1 온보딩
| 단계 | 카피 |
|---|---|
| 환영 | "안녕하세요. 저랑 같이 우리 동네를 누벼볼까요?" |
| 고양이 정하기 | "이 친구, 이름을 지어줄래요? 털색도 골라봐요." |
| 위치 권한 | "어디를 다녀왔는지 알아야 발자국을 남길 수 있어요. 위치를 켜주실래요?" |
| 알림 권한 | "도착하면 제가 살짝 알려드릴게요. 알림만 켜두시면 돼요." |
| 내 동네 확인 | "여기가 우리 동네가 맞나요?" |
| 튜토리얼 3컷 | ① "다녀온 곳에 발자국을 남기고" ② "발자국이 쌓이면 아지트가 자라요" ③ "안개가 걷히면 제가 뛰어놀 곳이 넓어져요." |
| 첫 발자국 | "자, 지금 여기. 첫 발자국을 남겨볼까요?" → "🐾 첫 발자국이 찍혔어요. 여기서부터 시작이에요." |

### 3.2 도착 알림 (지오펜스 — 유일한 알림)
- 기본: **"○○ 오셨네요. 발자국 남길까요?"**
- 단골: "또 왔네요, ○○. 여기 자주 오시네요 :)"
- 찜한 곳 첫 방문: "가고 싶다던 ○○, 드디어 왔어요!"

### 3.3 체크인 시트
| 상황 | 카피 |
|---|---|
| 다음 단계 힌트 | "한 번 더 오면 여기가 **작은 집**이 돼요." |
| 발자국 버튼 | "발자국 남기기" |
| 사진 버튼 | "순간 남기기 📷 (선택)" |
| 근접 밖 | "조금만 더 가까이 가면 발자국을 남길 수 있어요." |
| 위치 못 잡음 | "잠깐, 위치를 확인하고 있어요…" |

### 3.4 성장 축하 (등급업)
- 발자국→박스: "여기 박스가 생겼어요 📦 마음에 드나 봐요."
- 박스→작은 집: "작은 집이 됐어요 🛖 자주 오시는군요."
- 작은 집→캣타워: "캣타워예요 🗼 여긴 우리 단골이네요."
- 캣타워→캣 팰리스: "🏰 캣 팰리스. 여긴 당신의 인생 장소예요."
- 거시: "우리 동네가 이제 **아늑한 동네**가 됐어요." / "여기, 이제 **고양이 영역**이에요. 당신이 이만큼 누볐어요."

### 3.5 아지트 상세 (고양이의 추억)
| 요소 | 카피 |
|---|---|
| 사진 있음 | "여기서의 순간들" |
| 사진 없음 | "아직 남긴 순간이 없어요. 다음에 오면 하나 남겨볼까요?" |
| 발자국 수 | "지금까지 N번 다녀왔어요" |

### 3.6 빈 상태·엣지 (슬프지 않게)
| 화면 | 카피 |
|---|---|
| 위시리스트 0 | "가고 싶은 곳이 있나요? 검색해서 찜해두면 지도에 표시돼요." |
| 코스 후보 0 | "이 근처는 벌써 다 개척했어요! 대단한데요." |
| 탐색 결과 0 | "음, 못 찾았어요. 다른 이름으로 찾아볼까요?" |
| 오프라인 | "지금은 연결이 안 돼요. 발자국은 잘 저장해뒀다가 연결되면 남겨둘게요." |
| 위치 권한 거부 | "위치가 꺼져 있어서 발자국을 남기기 어려워요. 켜두시면 제가 도와드릴게요." |

### 3.7 시스템/계정
- 로그아웃: "다음에 또 만나요."
- 계정 탈퇴: "정말 떠나시겠어요? 그동안 함께 누빈 동네와 순간들이 모두 지워져요."
- 오류: "앗, 잠깐 문제가 생겼어요. 다시 해볼까요?" (에러코드 노출 금지)

## 4. 마이크로카피 원칙
- 버튼은 **행동 + 다정함**: "발자국 남기기", "순간 남기기", "같이 가볼까요".
- 시스템 용어 금지("동기화 완료" ❌).
- 숫자는 성장 근거로만("N번 다녀옴"), 경쟁·점수로 쓰지 않기.
- 이모지: 등급(🐾📦🛖🗼🏰)·거시(🌫️🌱🏘️🐾👑)는 시스템 상징으로 일관. 카피 내 장식 이모지 절제.

---

## 5. 디자인팀 전달 요약
- 고양이: 1마리, 상태 몇 개(상주/축하/안내/감정) + 커스터마이즈 색/무늬. 둥글고 따뜻, 앰버 기반.
- 등급: 발자국→박스→작은집→캣타워→캣 팰리스. 모양+크기 구분, 색 앰버 고정.
- 톤: 심시티·경찰·감시 금지. 동물의숲/피크민 결.
